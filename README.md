# 🧠 Applied Machine Learning Lab Experiments

## 📌 Overview

This repository contains a collection of Applied Machine Learning (AML) experiments covering various real-world problems such as classification, regression, prediction, and data preprocessing using Python and machine learning libraries.

---

## 🎯 Objectives

* Apply machine learning techniques to real-world datasets
* Understand data preprocessing and feature engineering
* Build and evaluate ML models
* Gain hands-on experience with different domains

---

## 🧪 Experiments Included

### 🔹 Credit Risk Assessment

* Predicts creditworthiness of individuals
* Classification problem

### 🔹 House Price Prediction

* Predicts house prices using regression models
* Focus on continuous value prediction

### 🔹 Iris Flower Classification

* Classifies iris flowers into different species
* Basic ML classification problem

### 🔹 MNIST Handwritten Digit Classification

* Recognizes handwritten digits (0–9)
* Image-based classification

### 🔹 Physiological Signal-Based Hand Gesture Recognition

* Classifies hand gestures using signal data
* Advanced classification problem

### 🔹 Pneumonia Diagnosis from Chest X-Ray Features

* Detects pneumonia using numerical features
* Includes feature engineering and model comparison

### 🔹 Python ML Libraries Practical Skills

* Practice using libraries like NumPy, Pandas, Scikit-learn

### 🔹 Data Preprocessing Report

* Covers data cleaning, transformation, and preparation techniques

### 🔹 Stock Price Prediction

* Predicts stock prices using ML models
* Time-series related problem

### 🔹 Telecom Customer Churn Prediction

* Predicts whether a customer will leave the service
* Business-oriented classification problem
